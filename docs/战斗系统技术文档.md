## 2. 架构设计

### 2.1 设计理念

战斗系统采用**ECS架构 + 纯函数算法**的混合设计:

- **ECS层** (`mir2::ecs`): 管理实体生命周期、状态变更、系统调度
- **核心算法层** (`legend2::combat`): 无状态纯函数,负责伤害计算、随机数等
- **Handler层** (`legend2::handlers`): 协议解析、业务逻辑入口

**关键设计原则**:
- **KISS**: 伤害计算采用简单直观的减法公式
- **YAGNI**: 只实现经典传奇必需的战斗机制
- **缓存友好**: 使用entt::group优化热路径遍历
- **线程安全**: thread_local随机数生成器

### 2.3 战斗流程

```
客户端发起攻击
    ↓
CombatHandler::HandleAttack
    ↓
CombatService::Attack
    ↓
验证攻击者状态
    ├─ HP<=0 → 返回失败:CHARACTER_DEAD
    └─ 正常 → CombatSystem::ExecuteAttack
        ↓
    检查目标有效性
        ├─ 无效 → 返回失败:TARGET_NOT_FOUND
        └─ 有效 → 检查距离
            ├─ 超出范围 → 返回失败:OUT_OF_RANGE
            └─ 范围内 → TakeDamageWithCalc
                ↓
            构建DamageInput
                ↓
            生成随机数Rolls
                ↓
            DamageCalculator::calculate
                ↓
            检查未命中
                ├─ 是 → 返回miss结果
                └─ 否 → 计算最终伤害
                    ↓
                应用暴击倍率
                    ↓
                TakeDamage扣除HP
                    ↓
                发布DamageDealtEvent
                    ↓
                目标HP<=0?
                    ├─ 是 → Die死亡处理
                    └─ 否 → 返回成功结果
```

**关键实现** (`combat_core.cpp:96`):
```cpp
DamageRolls CombatRandom::roll_damage(int base_damage, const CombatConfig& config) {
    DamageRolls rolls;
    if (base_damage > 0) {
        int min_var = (base_damage * config.min_variance_percent) / 100;
        int max_var = (base_damage * config.max_variance_percent) / 100;
        if (min_var < max_var) {
            rolls.variance = roll_int(min_var, max_var);
        }
    }
    rolls.critical_roll = roll_chance();
    rolls.miss_roll = roll_chance();
    return rolls;
}
```

### 4.3 AOE攻击实现

**文件**: `combat_system.cc:87`

```cpp
std::vector<entt::entity> collect_wide_hit_targets(
    entt::registry& registry,
    entt::entity attacker,
    const mir2::common::Position& center,
    int aoe_radius
) {
    std::vector<entt::entity> targets;
    const int radius = std::max(0, aoe_radius);
    constexpr float kSqrt2 = 1.41421356237f;
    const float query_radius = static_cast<float>(radius) * kSqrt2;

    SpatialQuery spatial_query(registry);
    auto candidates = spatial_query.get_entities_in_radius(center, query_radius);

    for (auto entity : candidates) {
        // 过滤:自己、死亡、不同地图
        const int dx = std::abs(state->position.x - center.x);
        const int dy = std::abs(state->position.y - center.y);
        if (dx <= radius && dy <= radius) {
            targets.push_back(entity);
        }
    }
    return targets;
}
```

## 5. 用户手册

### 5.1 战斗基础

#### 5.1.1 普通攻击

**操作**: 点击目标怪物或按攻击快捷键

**限制**:
- 攻击范围: 1格(近战) / 3格(刺杀/逐日)
- 攻击冷却: 由攻击速度决定
- 目标必须存活且在同一地图

**伤害计算**:
```
基础伤害 = 攻击力 - 防御力
浮动伤害 = 基础伤害 * [-10%, +10%]
最终伤害 = 基础伤害 + 浮动伤害
```

**特殊情况**:
- 暴击: 5%基础概率,伤害x1.5
- 未命中: 5%基础概率,伤害为0
- 最小伤害保证: 至少造成1点伤害

#### 5.1.3 魔法技能

**法师/道士技能伤害计算**:

```
魔法威力 = 魔攻 + get_power(技能, 技能等级)
if (目标是亡灵) 魔法威力 *= 1.5
最终伤害 = max(1, 魔法威力 - 魔防)
```

**治疗术公式**:
```
治疗量 = get_power(技能, 技能等级) * (1 + SC / 100)
```

**元素抗性**:
```
实际伤害 = 原始伤害 * (100 - 抗性%) / 100
```

### 7.5 常见问题FAQ

**Q: 为什么伤害有时候是0?**
A: 可能是未命中(5%概率)或攻击力低于防御力且随机浮动为负。

**Q: 暴击率能否超过100%?**
A: 代码中会clamp到[0, 1]范围,超过100%不生效。

**Q: AOE攻击为何无法击中某些目标?**
A: 需要检查目标是否在半径内、是否存活、是否在同一地图。使用`collect_wide_hit_targets`函数已包含这些检查。

**Q: 如何禁用暴击/闪避?**
A: 修改`CombatConfig`:
```cpp
config.base_critical_chance = 0.0f;
config.base_miss_chance = 0.0f;
```

**Q: 技能伤害是否受装备加成影响?**
A: 物理技能会叠加`attack`属性加成,魔法技能会叠加`magic_attack`加成。装备加成在`build_damage_input`中自动计算。
