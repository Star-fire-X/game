# 行会系统用户故事文档

## 1. 系统概述

行会系统是mir2游戏服务器的核心社交系统，负责管理玩家组织、行会战争、同盟关系等功能。系统包含行会创建与管理、成员职位体系、行会战争、同盟系统、门派对战等多个子系统，为玩家提供丰富的团体社交玩法。

## 3. 行会职位与权限对比表

### 3.1 职位等级定义

| 职位等级 | 职位类型 | 默认名称 | 权限说明 |
|---------|---------|---------|---------|
| 1 | 会长 | 掌门人 | 最高权限，可管理所有行会事务 |
| 2-98 | 自定义职位 | 自定义 | 由会长设置，权限介于会长和普通成员之间 |
| 99 | 普通成员 | 成员 | 默认职位，新成员加入时的等级 |

### 3.2 职位权限矩阵

| 权限项 | 会长(Rank=1) | 副会长(Rank≤2) | 普通成员(Rank=99) |
|-------|-------------|---------------|------------------|
| 修改行会公告 | ✓ | ✓ | ✗ |
| 修改职位结构 | ✓ | ✗ | ✗ |
| 邀请新成员 | ✓ | ✓ | ✗ |
| 踢出成员 | ✓ | ✓(低级别) | ✗ |
| 宣战/停战 | ✓ | ✗ | ✗ |
| 结盟/解盟 | ✓ | ✗ | ✗ |
| 申请攻城战 | ✓ | ✗ | ✗ |
| 解散行会 | ✓ | ✗ | ✗ |

### 3.3 职位更新规则

**位置**: [Guild.pas:554-761](Source/M2Server/Guild.pas#L554-L761)

| 错误码 | 含义 | 说明 |
|-------|------|------|
| 0 | 更新成功 | 职位结构已更新 |
| -1 | 无变化 | 与现有职位相同 |
| -2 | 会长缺失 | 必须有会长职位 |
| -3 | 会长名称为空 | 会长名称不能为空 |
| -4 | 会长数超限 | 会长数不能超过2人 |
| -5 | 会长不在线 | 至少一个会长必须在线 |
| -6 | 成员不匹配 | 成员列表与原有不符 |
| -7 | 等级无效 | 职位等级重复或超出范围 |
