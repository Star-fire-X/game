# 角色成长系统用户故事文档

## 1. 系统概述

角色成长系统是mir2游戏服务器的核心RPG系统，负责管理玩家角色的等级提升、属性成长、技能学习和装备加成。系统采用职业差异化设计，战士、法师、道士三大职业拥有不同的成长曲线和属性侧重。

### 1.1 核心文件索引

| 文件路径 | 主要职责 | 关键行号 |
|---------|---------|---------|
| [Grobal2.pas](Source/Common/Grobal2.pas) | 数据结构定义、属性常量、职业常量 | 175-186, 477-499, 603-626 |
| [ObjBase.pas](Source/Mir200/ObjBase.pas) | TCreature基类、经验计算、升级处理、属性重算 | 4204-4428, 4815-4880 |
| [M2Share.pas](Source/Mir200/M2Share.pas) | 经验表、职业加成系数、奖励点数计算 | 103-166, 170-210, 366-415 |

| [UsrEngn.pas](Source/Mir200/UsrEngn.pas) | 玩家管理、经验分配、组队系统 | 全文件 |

## 2. 核心数据结构

### 2.1 TAbility - 角色能力值记录

**位置**: [Grobal2.pas:477-499](Source/Common/Grobal2.pas#L477-L499)

```pascal
TAbility = record
  Level         : byte;      // 角色等级 (1-61)
  AC            : word;      // 物理防御力 (Armor Class)
  MAC           : word;      // 魔法防御力 (Magic Armor Class)
  DC            : word;      // 物理攻击力 (MakeWord(min,max)格式)
  MC            : word;      // 魔法攻击力 (Magic Class)
  SC            : word;      // 道术攻击力 (Spirit Class)
  HP            : word;      // 当前生命值
  MaxHP         : word;      // 最大生命值
  MP            : word;      // 当前魔法值
  MaxMP         : word;      // 最大魔法值
  Exp           : longword;  // 当前经验值
  MaxExp        : longword;  // 升级所需经验值
  Hit           : word;      // 命中率
  Speed         : word;      // 速度/敏捷

  MaxWearWeight : byte;      // 最大穿戴重量(不含武器)

end;
```

## 5. 详细用户故事

### US-GROW-001: 经验值获取计算

**用户故事**: 作为玩家，当我击杀怪物时，我需要根据怪物等级和我的等级差获得相应的经验值。

**优先级**: P0 (核心功能)
**复杂度**: 中等

**验收标准**:
1. 玩家等级 < 怪物等级+10时，获得全额经验
2. 玩家等级 >= 怪物等级+10时，经验递减
3. 经验递减公式: `exp - Round((exp/15) * (玩家等级 - (怪物等级+10)))`
4. 最低经验值为1，不会为0或负数

**技术实现要点**:
- 计算函数: [ObjBase.pas:4204-4218](Source/Mir200/ObjBase.pas#L4204-L4218) `CalcGetExp`
- 参数: targlevel(目标等级), targhp(目标HP/经验基数)

```pascal
function TCreature.CalcGetExp(targlevel, targhp: integer): integer;
begin
  if Abil.Level < (targlevel+10) then
    Result := targhp
  else
    Result := targhp - Round((targhp/15) * (Abil.Level - (targlevel+10)));
  if Result <= 0 then Result := 1;
end;
```

### US-GROW-002: 等级提升触发

**用户故事**: 作为玩家，当我的经验值达到升级所需经验时，我需要自动升级并获得属性提升。

**技术实现要点**:

- 升级处理: [ObjBase.pas:4395-4428](Source/Mir200/ObjBase.pas#L4395-L4428) `HasLevelUp`

```pascal
if Abil.Exp >= Abil.MaxExp then begin
  Abil.Exp := Abil.Exp - Abil.MaxExp;
  Inc(Abil.Level);
  HasLevelUp(Abil.Level-1);
  AddBodyLuck(100);
```

### US-GROW-005: 奖励点数发放

**用户故事**: 作为玩家，当我升级到21级及以上时，我需要获得可分配的奖励点数。

**优先级**: P1 (重要功能)
**复杂度**: 中等

**验收标准**:
1. 等级 <= 20: 无奖励点数
2. 等级 21+: 战士20点起，法师27点起，道士28点起
3. 每10级额外增加: 战士+5，法师+8，道士+9
4. 奖励点数累计计算

**技术实现要点**:
- 计算函数: [M2Share.pas:366-400](Source/Mir200/M2Share.pas#L366-L400) `GetBonusPoint`
- ADJ_LEVEL = 20 (属性调整起始等级)

```pascal
function GetBonusPoint(job, lv: integer): integer;
begin
  Result := 0;
  case job of
    0: if lv >= ADJ_LEVEL+1 then Result := Round(20 + (lv div 10) * 5);
    1: if lv >= ADJ_LEVEL+1 then Result := Round(27 + (lv div 10) * 8);
    2: if lv >= ADJ_LEVEL+1 then Result := Round(28 + (lv div 10) * 9);
  end;
end;
```
