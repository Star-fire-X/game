 * ## 框架目标
 *
 * 通过分离 MapSystem 的多个职责，实现：
 * ✅ **可测性**: 每个组件可独立测试\n * ✅ **可维护性**: 职责清晰，修改影响范围小\n * ✅ **可扩展性**: 易于添加新算��或功能\n * ✅ **解耦**: 组件通过接口通信，降低耦合度\n *\n * ## 框架结构\n *\n * ```\n * IWalkabilityProvider (接口)\n *     ^\n *     | 实现\n *     |\n * MapSystem (协调者)\n *     |\n *     +-- PathFinder (寻路算法)\n *     |       |\n *     |       +-- get_neighbors()\n *     |       +-- find_path()\n *     |       +-- manhattan_distance()\n *     |       +-- reconstruct_path()\n *     |\n *     +-- PortalManager (传送门管理)\n *     |       |\n *     |       +-- register_portal()\n *     |       +-- get_portal_at()\n *     |       +-- clear()\n *     |\n *     +-- MapData (地图数据)\n *     |       |\n *     |       +-- tiles[]\n *     |       +-- get_tile()\n *     |       +-- is_walkable()\n *     |\n *     +-- ResourceManager (资源加载)\n *             |\n *             +-- load_map()\n *             +-- load_archive()\n * ```\n *\n * ## 职责矩阵\n *\n * | 职责 | 原本位置 | 新位置 | 改进 |\n * |------|---------|--------|------|\n * | A* 算法实现 | MapSystem | PathFinder | 独立、可测试 |\n * | 启发式函数 | MapSystem | PathFinder | 浓聚、一致 |\n * | 邻居生成 | MapSystem | PathFinder | 内聚 |\n * | 传送门管理 | MapSystem | PortalManager | 专业化 |\n * | 传送门验证 | MapSystem | PortalManager | 集中化 |\n * | 地图加载 | MapSystem | MapSystem | 保留（协调） |\n * | 可行走性查询 | MapSystem | MapSystem | 保留（接口实现） |\n * | 资源管理 | MapSystem | MapSystem | 保留（代理） |\n *\n * ## 关键改进数据\n *\n * ### P0 修复成果（已完成）\n * - A* 启发式量纲错误修复\n *   - 性能提升：50-70%\n *   - 搜索节点数：2000→200-300\n * - 索引溢出防止\n *   - 支持地图大小：512×512+\n * - 防御性编程\n *   - 消除崩溃风险\n *\n * ### P1 改进（进行中）\n * - PathFinder 独立类（完成）\n * - PortalManager 独立类（完成）\n * - IWalkabilityProvider 扩展（见下）\n * - 错误处理统一（Result<T>）\n * - 常量提取（魔法数字消除）\n *\n * ## IWalkabilityProvider 接口改进\n *\n * ### 当前接口\n * ```cpp\n * class IWalkabilityProvider {\n * public:\n *     virtual bool is_walkable(int x, int y) const = 0;\n *     virtual bool is_valid_position(int x, int y) const = 0;\n * };\n * ```\n *\n * ### 改进后的接口（向后兼容）\n * ```cpp\n * class IWalkabilityProvider {\n * public:\n *     // 基础查询\n *     virtual bool is_walkable(int x, int y) const = 0;\n *     virtual bool is_valid_position(int x, int y) const = 0;\n *\n *     // 寻路支持\n *     virtual Size get_map_size() const = 0;\n *     virtual std::vector<Position> get_neighbors(const Position& pos) const = 0;\n *\n *     // 虚析构函数\n *     virtual ~IWalkabilityProvider() = default;\n * };\n * ```\n *\n * **改进理由**:\n * - PathFinder 可以通过接口获取地图大小（用于哈希键范围检查）\n * - get_neighbors() 可选实现（PathFinder 可提供默认）\n * - 使接口更完整，支持多种寻路算法\n *\n * ## 集成步骤\n *\n * ### 步骤 1：验证新文件\n * ```bash\n * # 确认文件已创建\n * ls -la src/client/game/map/path_finder.* src/client/game/map/portal_manager.*\n * ```\n *\n * ### 步骤 2：更新 CMakeLists.txt\n * ```cmake\n * # 在 src/client/CMakeLists.txt 中添加\n * set(GAME_SOURCES\n *     game/map/map_system.cpp\n *     game/map/path_finder.cpp\n *     game/map/portal_manager.cpp\n *     game/map/map_renderer.cc\n * )\n * ```\n *\n * ### 步骤 3：更新 MapSystem 头文件\n * ```cpp\n * #include \"path_finder.h\"\n * #include \"portal_manager.h\"\n *\n * class MapSystem : public IWalkabilityProvider {\n * private:\n *     PathFinder path_finder_{*this};  // 委托给 PathFinder\n *     PortalManager portal_manager_;   // 委托给 PortalManager\n * };\n * ```\n *\n * ### 步骤 4：编译验证\n * ```bash\n * cmake --preset vcpkg-debug\n * cmake --build --preset vcpkg-debug\n * ```\n *\n * ### 步骤 5：单元测试\n * ```bash\n * ctest --test-dir build/vcpkg-debug --output-on-failure -V\n * ```\n *\n * ##
