## 2. 架构设计

### 2.1 设计理念

技能系统采用**数据驱动 + ECS架构**的设计:

- **数据驱动**: 技能模板通过YAML配置文件加载,无需修改代码即可添加/调整技能
- **ECS架构**: 技能状态作为组件附加到实体上,解耦数据与逻辑
- **单例注册表**: SkillRegistry提供全局统一的技能模板访问
- **事件驱动**: 技能施放、学习、升级通过事件总线通知

**关键设计原则**:
- **KISS**: 技能威力公式简单明了(基于传奇经典公式)
- **YAGNI**: 只实现传奇必需的技能类型(物理/魔法/治疗/BUFF/DEBUFF)
- **可配置**: 所有技能数据外置于YAML,易于调整平衡
- **线程安全**: SkillRegistry使用shared_mutex支持多线程读

### 2.3 技能施放流程

```
客户端发起技能施放
    ↓
SkillSystem::cast_skill()
    ↓
1. 验证技能已学习
    ├─ 未学习 → 返回失败:SKILL_NOT_LEARNED
    └─ 已学习 → 继续
    ↓
2. validate_cast() 验证施法条件
    ├─ MP不足 → 返回失败:INSUFFICIENT_MP
    ├─ 护身符不足 → 返回失败:ITEM_NOT_FOUND
    ├─ 冷却中 → 返回失败:SKILL_ON_COOLDOWN
    ├─ 正在施法 → 返回失败:INVALID_ACTION
    └─ 通过验证 → 继续
    ↓
3. 消耗资源
    ├─ 扣除MP
    ├─ 消耗护身符耐久度
    └─ 开始冷却计时
    ↓
4. 是否需要引导施法?
    ├─ 是 (cast_time_ms > 0)
    │   ├─ 创建CastingComponent
    │   ├─ 广播施法特效
    │   └─ 返回成功(等待update完成施法)
    └─ 否 (即时施放)
        ↓
    5. collect_targets() 收集目标
        ├─ SELF: 目标=施法者
        ├─ SINGLE: 目标=指定实体
        └─ AOE: 使用SpatialQuery查询半径内所有实体
        ↓
    6. apply_skill_effect() 对每个目标应用效果
        ├─ PHYSICAL: DamageCalculator::calculate_physical_damage
        ├─ MAGICAL: DamageCalculator::calculate_magic_damage
        ├─ HEAL: DamageCalculator::calculate_healing
        ├─ BUFF/DEBUFF: 添加ActiveEffect到EffectListComponent
        └─ DoT: 添加持续伤害效果
        ↓
    7. 广播命中特效
        ↓
    8. 发布SkillCastEvent事件
        ↓
    返回SkillCastResult(成功)
```

```cpp
    const int scaled = scale_power(skill.min_power, skill.train_lv, skill_level);
    return scaled + skill.def_power;
}

// 内部辅助函数
int scale_power(int value, int train_level, int skill_level) {
    const int clamped_train = std::max(0, train_level);
    const int clamped_skill = std::max(0, skill_level);
    const double scaled = static_cast<double>(value) / (clamped_train + 1) * (clamped_skill + 1);
    return static_cast<int>(std::round(scaled));
}
```

**公式**:
```
威力 = ROUND(min_power / (train_lv + 1) * (skill_level + 1)) + def_power
```

**示例**:
```
技能: 火球术 (min_power=10, def_power=2, train_lv=2)
当skill_level=3时:
威力 = ROUND(10 / 3 * 4) + 2 = ROUND(13.33) + 2 = 13 + 2 = 15
```

#### 4.1.2 物理技能伤害计算

**文件**: `damage_calculator.cc:61`

```cpp
int calculate_physical_damage(const CharacterAttributesComponent& attacker,
                               const CharacterAttributesComponent& defender,
                               const SkillTemplate& skill,
                               int skill_level) {
    const int base_power = attacker.attack + get_power(skill, skill_level);
    const int scaled_range = scale_power(skill.max_power - skill.min_power,
                                         skill.train_lv, skill_level);
    const int attack_power = get_attack_power(base_power, scaled_range, attacker.luck);
    int damage = std::max(1, attack_power - defender.defense);

    // 应用剑术技能修正(如攻杀1.5x、开天2.0x)
    const AttackType attack_type = get_attack_type_for_skill(skill.id);
    const AttackTypeModifier modifier = get_attack_modifier(attack_type);
    damage = apply_attack_modifier(damage, modifier, 0);

    return damage;
}
```

**公式**:
```
攻击力 = 角色攻击 + 技能威力
攻击范围 = 技能威力范围缩放
最终攻击 = 攻击力 + Random(0, 攻击范围) + 幸运暴击修正
伤害 = max(1, 最终攻击 - 防御) * 技能修正倍率
```

### 4.2 目标收集算法

**文件**: `skill_system.cc:69`

```cpp
std::vector<entt::entity> collect_targets(entt::registry& registry,
                                          entt::entity caster,
                                          entt::entity target,
                                          const Position* target_pos,
                                          const SkillTemplate& skill) {
    std::vector<entt::entity> targets;

    // 1. SELF类型:施法者自己
    if (skill.target_type == SkillTarget::SELF) {
        targets.push_back(caster);
        return targets;
    }

    // 2. SINGLE类型:单体目标
    if (skill.target_type == SkillTarget::SINGLE_ENEMY ||
        skill.target_type == SkillTarget::SINGLE_ALLY) {
        if (is_valid_entity(registry, target)) {
            targets.push_back(target);
        }
        return targets;
    }

    // 3. AOE类型:范围内所有目标
    if (skill.aoe_radius > 0.0f) {
        bool has_center = false;
        const Position center = resolve_center_position(
            registry, caster, target, target_pos, &has_center);
        if (!has_center) {
            return targets;
        }

        SpatialQuery spatial_query(registry);
        const auto candidates = spatial_query.get_entities_in_radius(
            center, skill.aoe_radius);

        for (auto entity : candidates) {
            // 过滤:检查地图、存活状态等
            targets.push_back(entity);
        }
    }

    return targets;
}
```

**算法**:
1. 根据`target_type`确定目标类型
2. SELF: 直接返回施法者
3. SINGLE: 返回指定的target
4. AOE: 使用空间查询收集半径内所有实体

```cpp
AttributeModifiers calculate_skill_bonus(uint32_t skill_id, uint8_t level) const {
    AttributeModifiers bonus{};
    const int clamped_level = std::min(3, static_cast<int>(level));

    switch (skill_id) {
    case SkillId::ONESWORD: {
        // 基础剑术:每级+1命中率
        bonus.hit_rate_bonus = clamped_level * 1;
        break;
    }
    case SkillId::BODYGUARD: {
        // 护体神功:每级+5防御
        bonus.defense_bonus = clamped_level * 5;
        break;
    }
    case SkillId::BLOODLUST: {
        // 嗜血术:每级+3攻击
        bonus.attack_bonus = clamped_level * 3;
        break;
    }
    case SkillId::WUJIZHENQI:
    case SkillId::TAOIST_WUJI: {
        // 无极真气:每级+2攻击+2防御
        bonus.attack_bonus = clamped_level * 2;
        bonus.defense_bonus = clamped_level * 2;
        break;
    }
    case SkillId::GHOSTSHIELD: {
        // 幽灵盾:每级+3魔防
        bonus.magic_defense_bonus = clamped_level * 3;
        break;
    }
    case SkillId::DEJIWONHO: {
        // 神圣战甲:每级+4防御
        bonus.defense_bonus = clamped_level * 4;
        break;
    }
    default:
        break;
    }

    return bonus;
}
```

### 7.4 常见问题FAQ

**Q: 为什么技能学不了?**
A: 检查职业、等级、技能槽位是否满足条件。使用`can_learn_skill`测试。

**Q: 技能伤害为什么这么低?**
A: 检查`min_power`、`max_power`、`def_power`、`train_lv`是否配置正确。使用`get_power`公式计算威力。

**Q: 技能无法施放?**
A: 检查MP、护身符、冷却、施法状态。查看`SkillCastResult.error_code`获取详细错误。

**Q: 修炼点如何获得?**
A: 使用技能攻击怪物自动获得。调用`add_training_points`手动添加用于测试。

**Q: AOE技能为何无法命中?**
A: 检查`aoe_radius`是否大于0,`target_type`是否为AOE类型。使用`collect_targets`调试目标收集。

**Q: 如何禁用技能冷却?**
A: 设置`cooldown_ms=0`。或在测试时不调用`start_cooldown`。

**Q: 被动技能如何生效?**
A: 学习后自动调用`recalculate_passives`,攻击时通过`trigger_on_attack`获取加成。

**Q: 引导施法如何取消?**
A: 调用`interrupt_casting`或在`CastingComponent`上设置`can_be_interrupted=false`。
